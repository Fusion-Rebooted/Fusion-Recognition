# How to get the data

Photos, trained weights and caches are not in git. They are on the team's server, reachable on the team VPN only. **Ask a maintainer for access and the URL** (`<DATA_URL>` below).

## Download everything

Inside the cloned repo:

```bash
wget -r -np -nH --cut-dirs=1 -c -R "index.html*" <DATA_URL>/
```

Every folder lands where the code expects it. `-c` resumes a broken download; rerun to fetch new files.

## Download only what you need

Add the folder to the URL, e.g. `<DATA_URL>/models/`.

| Goal | Folders |
|---|---|
| Recognise bricks | `runs/detect/runs/box/` (brick finder). `models/shape_embed.pt` and `data/gallery.npz` are already in git |
| Rerun a notebook | the **Needs** line at the top of that notebook |
| Rebuild everything from scratch | `dataset/`, `ldraw/`, `real/`, `labeling/images/` (everything else is regenerated by the notebooks) |

What each folder is: [Folders](../reference/folders.md).

## Upload (maintainers)

From the repo root:

```bash
rsync -avP --relative <folders...> <user>@<server>:<data path>/
```

`--relative` keeps the repo layout on the server. Only new or changed files are sent.
